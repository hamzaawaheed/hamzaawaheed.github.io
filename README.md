# Hamza Waheed — BI Portfolio

This is a static portfolio website. `index.html` links to the resume at `assets/Hamza_Waheed_BI_Resume.pdf` and the profile image at `assets/profile.png`.

## View locally
Open `index.html` in a browser. Use **Download Resume (PDF)** to download the 2-page resume.

## Publish via GitHub Pages
Upload the files inside this directory (`index.html` and the `assets` folder) to the root of a GitHub repository. In Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save. The relative resume download link will work on the published page.

If the resume changes, replace `assets/Hamza_Waheed_BI_Resume.pdf` with the new PDF under the same name, then redeploy.

Only publish resume contact details if you are comfortable making them public.
